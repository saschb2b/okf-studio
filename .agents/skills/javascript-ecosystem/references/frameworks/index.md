# UI frameworks

- [Angular](angular.md) - Angular is signal-first and zoneless.
- [React Compiler rules (full teachable reference)](react-rules.md) - Self-contained reference for enabling the React Compiler safely, so this skill teaches the whole thing without any other skill installed.
- [React](react.md) - React 19 made Actions, the `use()` primitive, `ref` as a regular prop, and `<form action>` first-class.
- [Solid](solid.md) - Signals stay the foundation (`createSignal`, `createMemo`, `createEffect`).
- [Svelte](svelte.md) - Svelte 5 replaced implicit reactivity with explicit runes (`$state`, `$derived`, `$effect`, `$props`, `$bindable`), which give fine-grained reactivity that also works in `.svelte.js` and...
- [Vue](vue.md) - `<script setup>` Composition API is the idiomatic default.
