# Internationalization

- [i18next (with react-i18next)](i18next.md) - i18next is now TypeScript-first.
- [next-intl](next-intl.md) - next-intl is App Router native with strict typing.
- [Paraglide JS (inlang)](paraglide.md) - Paraglide is compiler-based, not a runtime dictionary.
- [Transloco (Angular i18n)](transloco.md) - Transloco is Angular's runtime i18n library, with live language switching, lazy scopes, and a signal-based API.
