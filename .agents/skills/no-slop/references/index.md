# The writing system and per-surface before/after guidance behind the no-slop skill.

- [no-slop: structural editing](structure.md) - The document-level pass. Reorder, merge, split, delete, and replace sections before any sentence gets polished.

- [no-slop: formatting](formatting.md) - Slop you can see before you read a word.
- [no-slop: prose before and after](prose.md) - Concrete rewrites for each tell.
- [no-slop: Microsoft style](microsoft-style.md) - The mechanics no-slop adopts from the Microsoft Writing Style Guide, the three places its brand voice contradicts no-slop, and the house-style mode that resolves them.
- [no-slop: inclusive and accessible prose](inclusive-and-accessible.md) - Writing rules for readers using assistive technology and for language that excludes, drawn from the Microsoft accessibility and bias-free guidance.
