# Per-surface before/after guidance behind the no-slop skill.

- [no-slop: code comments](code-comments.md) - The slop comment is written for the reviewer of one change and then stranded in code that outlives the review.
- [no-slop: strings in code](code-strings.md) - Test names, error messages, and log lines are read by a human at the worst moment, when a test fails or production breaks.
- [no-slop: commit messages and PR descriptions](commits-and-prs.md) - Both describe a change to someone reading it later.
- [no-slop: formatting](formatting.md) - Slop you can see before you read a word.
- [no-slop: prose before and after](prose.md) - Concrete rewrites for each tell.
