# Aufgabe

Das Interoperabilitätslabor zeigt mehrsprachige Varianten, externe Bundle-Verweise, JSON-LD-Beziehungen und Begleitdateien als begrenzte Experimente. Diese Metadaten verändern die OKF-Konformität nicht.

Die vollständige Produktbeschreibung steht im englischen Konzept [Interoperability Lab](interoperability-lab.md).
