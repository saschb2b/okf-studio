# Update Log

## 2026-06-29
* **Update**: Replaced the native window decorations with a **custom title bar** (Zed-inspired). The window runs borderless; the [top bar](ux/browsing-layout.md) becomes the title bar — a drag region (double-click to maximize) with **minimize / maximize / close** controls at the right and invisible **resize handles** at the window edges. Recorded in [Theming](ux/theming.md) and the [capabilities](architecture/ipc-and-security.md) (added the least-privilege `window` permissions: start-dragging, start-resize-dragging, minimize, toggle-maximize, close, is-maximized).
* **Update**: Reworked the [Concept Reader](features/concept-reader.md) into a reading-first design (reading is a core value), evaluated by five reader personas (skimmer, deep reader, accessibility, knowledge-navigator, product-designer). The spec now calls for a **centered, character-capped prose column** (no more flush-left column with a dead right gutter), a **quiet right context rail** (On this page outline with scroll-spy · Cited by · Links to · Related by tag · Details · Broken links) that collapses responsively, a **polished Markdown renderer** (readable type scale, anchored headings, GFM-alert callouts, code copy buttons, legible tables, underlined links with in-bundle/external/broken affordances), a **breadcrumb**, and an **"Aa" reading-preferences** control (size · measure · line spacing · font · reading aids), with [reading-layer tokens](ux/theming.md) and a reader-composition note in [Browsing Layout](ux/browsing-layout.md). Ships in phases (reading comfort → rail → renderer polish → preferences).
* **Update**: Designed a top-left [Bundle Switcher](features/bundle-switcher.md) (Zed-seeded) to replace bundle switching scattered across the sidebar bundle list and the recent list buried in [Settings](ux/settings.md). It names the open bundle, switches among the bundles in the open folder, and reopens **recent bundles** — recents are per-bundle, with the containing folder kept underneath only as the read [scope](architecture/ipc-and-security.md) — plus pin/remove, an "Open folder…" action, and a disabled "Open remote folder… (coming soon)" placeholder; opens with `Ctrl/Cmd + P`. Renamed the `bundle-browser` concept to [bundle-switcher](features/bundle-switcher.md) and threaded it through [layout](ux/browsing-layout.md), [settings](ux/settings.md), [first-run](ux/first-run.md), [keyboard](ux/keyboard-shortcuts.md), [detection](architecture/bundle-detection.md), [performance](architecture/performance.md), [validation](features/validation.md), and [IPC](architecture/ipc-and-security.md); recorded **folder-as-workspace grouping** as a [post-v1 direction](product/scope-and-non-goals.md). Design/spec only — no app code yet.
* **Update**: Shipped the five UX/UI proposals and folded them back into the feature/UX concepts (the `proposals/` directory is now removed). Delivered: a **global search launcher** ([Command Palette](features/command-palette.md)) reachable from the header field, `Ctrl/Cmd + K`, and `/`, with grouped Recent / Concepts / In-text / Actions results and full-text body [search](features/search-and-filter.md); a **scalable sidebar** with a Navigate/Filter [lens switcher](ux/browsing-layout.md) (separating [navigation](features/navigation.md) from [filters](features/search-and-filter.md)); a **focus mode** for the [Graph View](features/graph-view.md) (ego-graph by adjustable depth, Overview/Focus toggle, orphan and broken-link surfacing); a **reader-first adaptive layout** with resizable, keyboard-operable panes and graph-only / split / reader-only [layout modes](ux/browsing-layout.md) (`Ctrl/Cmd + 1/2/3`, `\`); and a **native desktop feel** — content-scoped reader text size replacing browser page-zoom ([Settings](ux/settings.md)), suppressed chrome context menu and page-zoom hotkeys, and themed native scrollbars ([Theming](ux/theming.md)). New [keyboard shortcuts](ux/keyboard-shortcuts.md) accompany each. Verified: `pnpm build` clean, 8/8 frontend tests, `cargo check` green.

## 2026-06-28
* **Update**: Switched the JS package manager from npm to **pnpm** (v10): migrated to `pnpm-lock.yaml`, allowed esbuild's build script via `pnpm.onlyBuiltDependencies`, and updated the [Tauri commands](reference/tauri-2.md) and project docs (README, AGENTS) to `pnpm`. Shared primitive styling lives in `src/components/baseui.css`.
* **Update**: Adopted **Base UI** (`@base-ui/react`, headless) for accessible component behavior, styled entirely by our [design tokens](ux/theming.md) — recorded in [Tech Stack](architecture/tech-stack.md) and [Frontend Architecture](architecture/frontend-architecture.md). Migrating component-by-component for UI conformity and maintenance stability; the **Settings dialog** is migrated first (Dialog + Select + Checkbox + Number Field), replacing its hand-rolled focus trap and native controls.
* **Creation**: Captured five post-v1 UX/UI improvements as proposals, each enriched from multi-persona analysis: a global search launcher, a scalable sidebar with navigation lenses, a more useful graph view, a reader-first adaptive layout, and a native desktop feel. (Proposals only at this point — all five were shipped and folded into the feature/UX concepts on 2026-06-29, and the proposal files removed.)
* **Update**: Introduced a single **design-token layer** ([Theming](ux/theming.md)) — spacing, type, radius, scrim, and focus scales on `:root` — and migrated the UI off raw literals (149 values across 8 component stylesheets plus the shared chrome) so spacing, type sizes, radii, and colors are consistent instead of ad-hoc. Removed `rgba()` color literals (scrim token + `color-mix`) per the theme-colors rule. Also added a stricter self-review workflow to AGENTS.md (run visual-consistency/theme-colors/react-stinky as a gate; verify with screenshots; no vibe sign-offs).
* **Update**: Adopted an Obsidian-style, scalable [Graph View](features/graph-view.md) strategy: **Barnes–Hut quad-tree** repulsion and a **collision** pass (see [Performance & Scale](architecture/performance.md)), level-of-detail labels, auto-fit on settle, hover/selection focus, and a collapsible controls panel for forces and display. Replaces the naive O(n²) layout that did not scale or read well.
