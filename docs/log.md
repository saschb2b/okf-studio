* **Fix**: Repaired the [Concept Reader](features/concept-reader.md)'s **"On this page" scroll-spy**. It had stopped tracking and could never highlight the trailing sections (short sections near the end can't scroll into a top band). * **Fix**: Stopped the [Graph View](features/graph-view.md) from **over-wiring** into a hairball. The docs bundle is richly cross-linked (~14 edges/node, ~39% density), and no force layout can untangle a near-complete graph — so we now draw a **structural backbone** instead of every edge, the decades-established edge-filtering answer for dense networks. Each edge is weighted by how much it reveals structure (mutual links + shared-neighborhood Jaccard + shared-tag Jaccard); each concept keeps only its strongest few (a weighted **k-nearest-neighbor** graph), with a **maximum spanning forest** overlaid so pruning never disconnects the graph. (Chose weighted top-k over the disparity filter, which goes degenerate on our near-binary weights — empirically verified on the real graph.) A Controls **Links: Key / Balanced / All** setting (default Balanced, in the store so both renderers share it) tunes density; **communities and focus neighborhoods still use the full link graph**, so colors and "what relates to this" stay complete. Applies to both the canvas and GPU renderers; new `graph/backbone.ts` with tests.
