# Retrieval intelligence

This product branch records how OKF Studio turns connected, versioned bundle knowledge into inspectable model context without adopting one mandatory RAG stack. The roadmap now includes the shipped implementation record and the boundaries that remain deliberately unavailable.

* [State of RAG systems](rag-state-and-failures.md) - Evidence review of current retrieval failures, alternatives, and community signals.
* [OKF retrieval thesis](okf-retrieval-thesis.md) - The product position, OKF advantages, missing primitives, and intended context engine.
* [Retrieval experience contract](retrieval-experience-contract.md) - Surface ownership, progressive disclosure, stable layout, state coverage, and prototype gates.
* [Retrieval intelligence roadmap](retrieval-intelligence-roadmap.md) - Sequenced experiments and work packages for a local-first, inspectable retrieval layer.
* [Retrieval operations](retrieval-operations.md) - Rebuild, diagnosis, provider removal, cache cleanup, migration, and rollback behavior.
* [Retrieval schema adapters](../../reference/retrieval-schema-adapters.md) - The stable manifest boundary for the built-in local engine and optional external vector stores.
