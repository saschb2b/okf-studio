# Proposals

Post-v1 UX/UI improvements captured for later implementation — each a `type: Proposal` concept (`status: proposed`), enriched from multi-persona analysis. They extend the [features](../features/) and [UX](../ux/) concepts; when one is implemented, fold its decision back into those concepts and append a [log](../log.md) entry.

* [Global Search Launcher](global-search.md) - Always-on header search and a hotkey fuzzy dialog, merged with the command palette.
* [Scalable Sidebar & Navigation Lenses](scalable-sidebar.md) - A lens switcher that separates filtering from navigation so large bundles stay scannable.
* [Graph View — From Picture to Tool](graph-from-picture-to-tool.md) - Default to a focused neighborhood, surface orphans and broken links, and isolate subgraphs.
* [Reader-First Adaptive Layout](reader-first-layout.md) - Resizable panes, reader/split/graph modes, and an opt-in adaptive auto-switch.
* [Native Desktop Feel](native-feel.md) - Scope zoom to content and suppress web defaults so the app feels native.
