# Proposals

Design directions not yet built — where the viewer is headed and why. Each is a spec an implementation can reference; see [Scope & Non-Goals](../product/scope-and-non-goals.md) for what has shipped.

* [Deep Knowledge Diving](deep-knowledge-diving.md) - The survey: where the viewer is thin for going deep, and the data-catalog and graph-explorer patterns worth borrowing.
* [Bundle Overview & Health](bundle-overview.md) - A landing view that orients you in a bundle before you dive.
* [Faceted Query Bar](faceted-search.md) - Structured field queries and facet rails that filter the workspace live.
* [Lineage & Traversal](lineage-and-traversal.md) - Expand-on-click, upstream/downstream lineage, path-between, and unlinked mentions.
* [Multi-View — Tabs & Windows](multi-view.md) - Reader tabs with per-tab history, browser-standard modifier clicks, and undocking a tab into its own window.
